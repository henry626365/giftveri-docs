# Gift card balance check: a practical checklist

A useful gift card balance record starts with the correct product. Before using a Windows client or a website, establish what the card is and which operation you need.

## Identify the card before choosing a checker

Write down the product name and purchase region without putting its private codes in a public note. A card sold at Walmart or Target can be a third-party prepaid card rather than that retailer's own gift card.

For a Visa product, the [official Visa balance guide](https://www.visa.com/en-us/personal/cards/gift/gift-card-balance) identifies issuer-specific routes. For a Target GiftCard, use [Target's balance instructions](https://www.target.com/help/articles/gift-cards/check-your-target-giftcard-balance). Match the exact product rather than choosing a familiar retailer name.

## Keep an operational record

| Field | Useful context | Public example |
| --- | --- | --- |
| Product | Issuer, card type and region | Example card A, US retailer gift card |
| Operation | Balance inquiry, payment or redemption | Balance inquiry |
| Returned amount | Only an explicit amount and currency | USD 25.00, invented for illustration |
| Result state | Returned, failed or unknown | Unknown when no amount is established |
| Request state | Clearly unsent, completed or uncertain | Uncertain, review before retrying |

This table is a documentation checklist, not an import schema or a real-card result. Do not include card numbers, PINs or security codes in public examples.

## Use GiftVeri within the matching scope

After selecting a brand and region, confirm that the installed version provides the required entry and that the brand page's current verification state suits the operation. Start with a single authorized card.

The [Windows setup guide](../docs/getting-started.md) covers installation. [Reading results](../docs/results.md) explains why an empty amount is not zero. For the current package, use the [gift card balance checker download](https://www.giftveri.com/en/download).

## Before moving to a list

Check workflow-specific batch availability as well as the plan. Keep completed and uncertain tasks separate from clearly unsent work. A plan label alone is not evidence that a brand has a batch implementation.

If a result is unclear, retain its context and continue with [gift card error triage](gift-card-error-triage.md).
