# Documentation changelog

This log tracks the public guides in this repository. Product release information is maintained on the [official Windows download page](https://www.giftveri.com/en/download).

## November 8, 2026: Documentation baseline

- Added four Apple gift card guides for balance records, product identification, region preflight and message triage.
- Made Apple topics the first section of the README and navigation; Apple now accounts for four of seven editorial topic guides.
- Organized the README around gift card balance checks, Visa and Vanilla card fields, and cards that are not working.
- Added three topic guides with practical checklists, issuer resources and links to the relevant client documentation.
- Distinguished balance checks from redemption and purchase declines; retained the development-build scope of the Vanilla US workflow.
- Documented the current Windows RAR extraction workflow and the `_internal` directory requirement.
- Added result examples that distinguish explicit balances, unknown amounts and session failures.
- Added troubleshooting and frequently asked questions.
- Added contribution guidance for accurate, redacted documentation updates.

The public download record checked for this documentation listed v0.4.10. This entry describes documentation work and is not a claim that the application changed on this date.
